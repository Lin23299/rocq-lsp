2. pet_checkpoint_arena.ml（材料与租约状态机，自持 Mutex）：
   - 上传 spool：transfer→{staging bytes/next_offset/expected digest+bytes/artifact_ref}；begin/chunk/finish 状态迁移（chunk offset 顺序、finish 总量+SHA-256 ⇒ 封存材料按 artifact_kind 入库）。

   - import arena：cache_id→{staging 材料集合(按 artifact_ref id)/phase Preparing|Prepared|Activated/graph 校验结果}。register_import_material（finish 封存时登记）、prepare（材料齐⇒graph 校验⇒Prepared）、activate（permit 校验⇒映射行进 Registry 线表⇒Activated）。
3. pet_checkpoint_dispatch.ml：
   - serve_blob_request（pet_native 的 source/view 帧分派接入）：BlobBeginRequest（核 checkpoint_transfer 与预算配对——用 T.checkpoint_input_budget/checkpoint_output_budget 给 (bytes 上界, deadline)，配对表按 checkpoint.rs checkpoint_transfer 的 allowed 矩阵同款：source 通道 begin/chunk/finish 只许上传方向、view 通道 pull/ack/release 只许下载；artifact kind 与 budget.initial_request method/phase 配对照抄 Rust 表）⇒ BlobBegun/BlobRegistered（已完整同身份幂等）；BlobChunkRequest（offset/块 digest）⇒ BlobChunkAck；BlobFinishRequest（总量摘要核）⇒ BlobRegistered（材料交 arena）；BlobPullRequest（seq/offset/credit 1..8192）⇒ BlobChunkOut（Base64 出块、end=到总量）；BlobAckRequest ⇒ BlobAcked；BlobReleaseRequest（reason+durable_record）⇒ 真实清理后 BlobReleased。回复统一 T.checkpoint_blob_result 编码。类型（transfer/artifact）不匹配或未登记 ⇒ T.checkpoint_blob_error。

     observe/export_collect/export_encode：本批无真实导出材料 ⇒ T.make_checkpoint_error（stage=CpValidate/CpCollect、started=false）错误终态（extent 非 UnknownTail——查 types.ml make_checkpoint_error 实现确认），存 op.aux。
     run_import：args_checkpoint_import 解包（ci_binding/ci_control/ci_attempt/ci_cache/ci_plan/ci_group/ci_manifest/ci_bundle/ci_compatibility 五 artifact_ref）；材料齐（arena 里 plan/manifest/bundle/compatibility 都已上传封存）⇒ graph.validate_import_map？注意 import 的 map 是下载方向的（ci 阶段还没有 map）——本批：材料齐 ⇒ requiremenets/manifest 结构校验（arena 存的 bytes 用 T.decode_checkpoint_requirements 等解回typed 再 graph.validate）⇒ arena phase Preparing→Prepared（登记私有恢复图：rows 留空、记 group）⇒ make_checkpoint_terminal (ImportedArtifact (args, mapping_artifact))——mapping artifact 本批用 manifest 同 bytes 造一个 CkMap artifact_ref（id: map-<cache>-<op>，注释说明本批由 manifest 材料派生、真实 map 由后续 owner 输入）。材料缺 ⇒ make_checkpoint_error (CpDecode, started=true)。graph 校验败 ⇒ (CpValidate, started=true)。
     run_activate：args_checkpoint_activate 解包（ca_binding/ca_import_receipt/activation/mapping）；核 activation permit（activation_id/ap_control_id=ci_control/ap_cache_id=cache/import_operation/import_receipt_key=ca_import_receipt/instance+epochs 与 header/binding_revision>0）与 arena（cache 存在、phase=Prepared、permit.import_operation 与导入终态 binding.operation 一致——Rust activation_group 同款核）；映射行进 Registry（本批 map rows 空 ⇒ 只登记 group 与激活记账：新线/新 context 的真实映射后续 owner 输入，注释声明）；⇒ make_checkpoint_terminal (ActivatedArtifact (args, group_id))（group 取导入终态的 group——用 arena 记的）。permit/arena 不符 ⇒ make_checkpoint_error (CpActivate, started=true)。幂等：同 binding 已有 aux ⇒ 重放。
